## 3. 现状摘要（截至 2026-03-10；回归证据基线见 docs/17 的最新可复现记录）

> 状态枚举以 `docs/16` 为准：`已实现且已验证 / 已实现但缺明确验证入口 / 部分实现 / 仅规划/长期蓝图`。

### 3.1 已实现且已验证（主干可交付）

- 核心账本闭环：多源 Source、会话检索/详情/事件时间线、usage/heatmap/drilldown、pricing、导出、归档（详见 [docs/15](./15-核心功能清单.md)、[docs/16](./16-全量规划功能核对矩阵.md)）。
- 企业治理首版：告警规则编排与分发闭环、外部联动失败治理与 DLQ、数据主权/复制任务、Rule Hub（含双人审批与版本 diff）、MCP 工具治理闭环、合规取证包、开放平台（OpenAPI/API Key/Webhook/8 语言 SDK）、Quality v2 基础、Replay v2 基础（详见 [docs/15](./15-核心功能清单.md)、[docs/16](./16-全量规划功能核对矩阵.md)）。
- Agent / C-S 基线：自动采集、状态观测、本地持久队列骨架、daemon 心跳与运行时视图、远程配置包 MVP、release/updater MVP、三平台冒烟与多架构构建/分发包验收、gRPC mTLS 本地端到端（详见 [docs/15](./15-核心功能清单.md)、[docs/17](./17-回归验证执行记录.md)）。

### 3.2 已实现，但仍需“待深化”（有入口，有能力边界缺口）

- Quality 高级版预测与建议：在现有 `forecast/advice + advice executions + 自动治理触发` 基础上，仍缺更高级预测模型与更丰富自动执行策略矩阵（详见 [docs/18](./18-剩余缺口清单.md)）。
- Replay “实验室”完全体：已有 experiments 与 compare/workflow/批量对比，但仍缺更完整实验编排与基线管理扩展（详见 [docs/18](./18-剩余缺口清单.md)）。
- MCP 企业编排深化：多阶段审批与 workflow 已打通，但仍缺更复杂条件库与更完整编排/可视化体验（详见 [docs/18](./18-剩余缺口清单.md)）。
- 企业 IAM 与合规深化：SCIM/SAML/MFA/风险登录、DLP 脱敏与分类属于“最小入口已补，企业级完全体未落地”（详见 [docs/18](./18-剩余缺口清单.md)）。
- 企业 C/S 深化：Store-and-Forward、本地队列、Policy Agent、远程配置下发深化、Updater 自动升级执行、企业静默安装与分发链路仍未形成完全体（当前已具备最小闭环与验收入口；详见 [docs/18](./18-剩余缺口清单.md)）。

### 3.3 部分实现（已有基线/预检，但未形成完整交付物）

- 多环境/多集群/SaaS 多租户 IaC 与运维资产：已有部署基线与预检入口，但未形成完整交付物（缺口说明见 [docs/18](./18-剩余缺口清单.md)，部署基线见 `docs/19`）。

## 5. TokenPulse×AgentLedger 对接基线摘要（v1 frozen）

- 唯一基线文档：[docs/integration/TOKENPULSE_AGENTLEDGER_V1.md](./integration/TOKENPULSE_AGENTLEDGER_V1.md)，冻结生效时间 `2026-03-07 12:36:08 +0800`。
- v1 协作边界：TokenPulse 负责 OAuth/网关/执行路由；AgentLedger 负责采集与治理；v1 只做 TokenPulse -> AgentLedger 单向“运行时终态摘要事件”投递，不做双向常驻同步。
- v1 传输与安全：HTTPS POST webhook；HMAC-SHA256；时间窗 ±300s；必须携带 `spec/keyId/timestamp/idempotency/signature` 并对原始 body 验签；幂等与持久化完成才允许返回 `200/202`。
